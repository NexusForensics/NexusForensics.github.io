Investigation Workflow

From live public content to a defensible case record.

The platform now covers the core path investigators need: case setup, visible evidence capture, OCR, target and identity review, local indexing, reporting, and optional team intelligence.

01

Capture

Preserve investigator-selected public profiles, posts, comments, screenshots, images, selected video frames, source URLs, and local files.

02

Review

Use OCR, keyword search, bookmarks, face matching, object/detail matching, and target checks to decide what matters.

03

Connect

Keep User Index cards, platform IDs, aliases, phone numbers, emails, profile URLs, media signatures, and prior captures tied to the case.

04

Report

Produce structured HTML evidence reports with thumbnails, timestamps, notes, hashes, manifests, and a visible source trail.

The outcome: evidence that remains understandable from collection through review.
