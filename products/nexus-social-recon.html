Features

Everything an investigator needs to preserve and understand public evidence.

Nexus Social Recon brings collection, review, connection, and reporting into one investigator-controlled workflow.

Visible capture

Case management

Actions

Capture first, then enrich without losing source context.

The workflow follows how investigators actually move through social evidence: preserve the page, mark what matters, index local signals, compare across unlocked cases when allowed, and package the record.

Step 1Open a case

Start from a local case workspace with agency and investigator context.

Step 2Capture sources

Save visible public pages, media, comments, and source-linked records.

Step 3Bookmark findings

Keep the strongest evidence visible across platform modules.

Step 4Index and compare

OCR, User Index links, friend identifiers, target checks, visual matching, and local cross-case lookup.

Step 5Export package

Generate reports, media folders, hashes, and disclosure-ready files.

Methodology

Move from public content to case-ready evidence.

The same method applies on every platform module, so a case reads the same no matter where the evidence came from.

Capture the source

  • Profiles, posts, comments, and replies
  • Images, selected video frames, screenshots, and local files
  • Source URLs retained with each capture

Review what matters

  • Local cross-case lookup

Reports

Evidence reports a reviewer can follow.

Nexus builds structured HTML reports from the investigator's preserved material. Every item links back to its source, its local file, and its hash.

Source-linked reports

Thumbnails, timestamps, source links, and local paths for each captured item.

Text and context

OCR text, comments, captions, and media details beside the capture.

Hashes and manifests

SHA-256 hash for every file, plus an evidence manifest for the package.

Person and activity reports

Single-person and activity reports, kept separate so nothing about other people is included.

Investigator narrative

A factual, chronological summary of what the investigator did, beside the technical record.

Protected export packages

Report packages can be password-protected with AES-256 for disclosure.

Hashing and Integrity

Every preserved file carries a fingerprint.

Hashes let a reviewer show that a file in the report is the same file that was captured, without taking anyone's word for it.

SHA-256

Hashed when it is saved

Captured screenshots, media, and exported files are hashed with SHA-256. The hash is written into the evidence report and the manifest next to the source URL and local path.

# illustrative manifest layout
file          sha256            source_url
capture-001   <64-character hash>   https://…
Verification

Re-check any file, any time

The Nexus Hashing Tool recalculates SHA-256 for any file on the same computer and lists the name, size, and hash, so it can be compared with the report.

Investigator actions are written to an audit log in the case, so the handling of the evidence can be reviewed as well as the evidence itself.

Encryption

Case data protected at rest, on the investigator's own machine.

Nexus is local-first: case files stay on the investigator's workstation or organization-controlled storage, and cloud processing is not required.

AES-256

Encrypted case vaults

A case can live in its own AES-256 encrypted volume that is mounted only while the case is open and unmounted when it is closed. Available on macOS.

Key management

Passphrase and recovery key

A vault opens with the investigator's passphrase or a one-time recovery key. Touch ID quick unlock is available on supported Macs. Keys are wrapped with scrypt and AES-256-GCM.

AES-256-GCM

Encrypted local index

The local cross-case index of OCR text, identifiers, and media signatures is encrypted, so cross-case memory does not leave searchable plaintext on disk.

AES-256

Protected export packages

Report packages can be password-protected for disclosure, with the password stored encrypted in the system keychain.

Previous Capture Detection

Know when evidence has already been captured.

Nexus Social Recon alerts the investigator when a profile, post, or exact source URL has already been preserved in an available case. It can also place the current capture beside prior case evidence for direct review. This helps prevent duplicate collection, directs investigators to existing evidence, and frees more time for new findings and deeper case analysis.

See feature levels Platform coverage

Seen Evidence

Captured before? You see it before you capture again.

When the page on screen is already preserved in a case, Seen Evidence says so. It shows how the match was made, when and by whom it was captured, and which case holds it.

One click opens the saved evidence, the source URL, or the case folder.

Previous Capture Detection shows where an exact URL or account identity was preserved and provides direct access to the saved evidence, source URL, and case folder.

Image Case Preview places the current capture beside prior case evidence, with the matched identifier, source URL, and local evidence path available for review.
