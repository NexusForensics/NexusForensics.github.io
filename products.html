Capability Ladder

Start with preservation, grow into intelligence.

Nexus can be packaged from focused capture through investigator analysis, local intelligence, small-team indexing, on-prem repositories, and managed deployments.

Level Primary Capabilities Evidence Output Best Fit
Capture Visible capture, source links, hashes, comments, local cases, and structured reports. HTML evidence reports, saved media, manifests, notes, and source trails. Focused public evidence preservation and report generation.
Investigator OCR, User Index enrichment, targets, profile review, face matching, object/detail matching, and active-case triage. Searchable captured text, explainable visual matches, profile context, and enriched reports. Investigators who need analysis tools inside individual cases.
Intelligence Local Index, global targets, same-computer cross-case lookup, and repeated identifier or media detection. Prior-capture alerts, local cross-case context, and repeat-signal summaries. Solo investigators or agencies that need local memory without a shared server.
Small Team / NAS Shared network index, NAS workflows, collaboration, admin governance, retention, audit logs, and support options. Governed shared evidence repositories and team-wide intelligence lookup. Organizations with shared evidence repositories or controlled infrastructure requirements.
